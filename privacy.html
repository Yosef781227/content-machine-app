Privacy Policy

Content Machine · last updated November 13, 2026

Who uses this app

Content Machine is a private tool used only by its owner to publish videos to the owner's own YouTube channel. It is not offered to the public.

What Google data the app uses

With the owner's permission (Google OAuth), the app uses the YouTube Data API to upload the owner's own videos and thumbnails and to set their title, description, tags and publishing time. It reads the name of the authorized channel to confirm it is uploading to the right channel.

What the app stores

  • An access token for the owner's YouTube account, kept privately on the owner's own server so uploads can run.
  • The owner's videos and their texts, kept only until the owner deletes them.

The app does not collect data about viewers or any other people, and it does not use Google user data for advertising.

Sharing

Google user data is not sold, shared with, or transferred to anyone. It is used only to provide the upload features described above. Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements, and the YouTube Terms of Service.

Removing access

The owner can revoke the app's access at any time at myaccount.google.com/permissions. Revoking access stops all uploads; the stored token becomes useless.

Contact

Questions: use the support email shown on the app's Google sign-in screen.
